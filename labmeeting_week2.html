  • v1 — 물리적 모순 발견 → 폐기
    • max_steps=6,000 (15초) 설정 상태에서 60m 하강 시도
    • 착지 조건: Vz ≤ 2 m/s → 최소 30초 필요 시간 부족
    • 에이전트가 착지 불가능한 환경에서 학습 → 착지율 0%

Context DB + Ontology 적용 (Stage 2 v4) 53.3% 달성
  • 문제 원인: CAUTION 구역(Vz/vh = 0.5~0.8)에서 학습 신호 부재
    • DANGER/RECOVER는 온톨로지가 추력 강제 증가로 이미 처리
    • CAUTION만 에이전트가 직접 학습해야 하는데 → 신호가 너무 희소
  • 해결: 사람이 마킹한 CAUTION 경계 상태 1,084개를 DB에 저장
    • 에이전트가 마킹 상태와 정규화 거리 <0.3 이내 진입 시 보상 +3.0
    • 학습 중 보너스 발생: 4,861,645회 → 희소 구역 학습 신호 충분히 보강
  • 결과: v3 2.0% → v4 53.3%
    • ep300 피크(~61%) 이후 점진적 하락, ep1,000 최종 53.3%
    • best 모델: stage2_v4_best.pth (ep300 기준) → Stage 3 시작점으로 사용
